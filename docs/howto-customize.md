# راهنمای شخصی‌سازی پلاگین بله

هدف: تنظیم پلاگین مطابق نیاز شما — چه کسی می‌تواند چت کند، به کجا اعلان‌ها بروند،
و تنظیمات رفتار ربات.

---

## پیش‌نیازها

- پلاگین بله نصب و کار می‌کند (اگر نه، [راهنمای نصب](howto-install.md))
- دسترسی به `~/.hermes/config.yaml` و `~/.hermes/.env`

---

## ۱. محدود کردن دسترسی: چه کسی می‌تواند با ربات چت کند؟

دو لایه کنترل دارید. **اگر `allow_from` تنظیم شده باشد، آن تنها مرجع است** و
هر دو لایه باید هماهنگ باشند.

### لایه ۱: در config.yaml

```yaml
gateway:
  platforms:
    bale:
      enabled: true
      extra:
        allow_from:
          - '66881162'          # شناسه شما
          - '987654321'         # شناسه دوستتان
```

- `allow_from` یک لیست است: فقط این شناسه‌ها می‌توانند پیام بفرستند.
- مقدار `*` یعنی همه مجازند (فقط برای تست — استفاده نکنید).

### لایه ۲: در .env

```bash
BALE_ALLOWED_USERS=66881162,987654321
```

### همه‌چیز را باز کنید (فقط تست)

```bash
BALE_ALLOW_ALL_USERS=1
```

> ⚠️ این گزینه را در محیط واقعی روشن نکنید — هر کسی می‌تواند از ربات شما استفاده کند.

### شناسه عددی حساب خود را پیدا کنید

1. به ربات پیام بدهید (هر پیامی).
2. در لاگ گیت‌وی دنبال `[Bale]` بگردید — شناسه شما آنجا دیده می‌شود:

   ```bash
   grep "\[Bale\]" ~/.hermes/logs/gateway.log | tail
   ```

3. یا با یک پیام به [@BotFather](https://ble.ir/botfather) دستور `/myid` را امتحان کنید (در صورت پشتیبانی).

---

## ۲. تنظیم مقصد پیش‌فرض اعلان‌ها (home channel)

اعلان‌های cron و گزارش‌ها به یک «چت خانگی» فرستاده می‌شوند:

```yaml
gateway:
  platforms:
    bale:
      home_channel:
        chat_id: '66881162'
        name: پیام شخصی
```

از داخل بله هم می‌توانید تنظیم کنید: به ربات `/sethome` بفرستید تا چت فعلی به
عنوان مقصد اعلان‌ها ثبت شود.

---

## ۳. تنظیم نوع رندر پیام (Markdown)

بله از **Markdown** و **HTML** پشتیبانی می‌کند، ولی **نه** MarkdownV2 (که تلگرام
دارد). این پلاگین از پیش روی `ParseMode.MARKDOWN` تنظیم شده است — نیازی به تغییر
ندارید.

اگر می‌خواهید خودتان پیام بفرستید، از همین دو حالت استفاده کنید:

```python
# ارسال با Markdown
await bot.send_message(chat_id, "*متن پررنگ*", parse_mode="Markdown")
# ارسال با HTML
await bot.send_message(chat_id, "<b>متن پررنگ</b>", parse_mode="HTML")
```

---

## ۴. رفتار رندر دکمه‌های انتخاب مدل (RTL)

پیکر مدل در این پلاگین برای **راست‌به‌چپ (RTL)** بهینه شده:

- دکمه‌های ناوبری فارسی هستند: «بعدی»، «قبلی»، «بازگشت»، «انصراف»
- «بعدی» در سمت راست و «قبلی» در سمت چپ است (مطابق جهت خواندن فارسی)
- نام‌های بلند مدل کوتاه می‌شوند تا در دکمه جا شوند

این رفتار در `_build_model_keyboard` و `_build_provider_keyboard` در `adapter.py`
پیاده شده و به‌صورت پیش‌فرض فعال است.

---

## ۵. تنظیمات رفتاری پیشرفته

از طریق متغیرهای محیطی می‌توانید رفتار پیام‌رسانی را تنظیم کنید:

| متغیر | پیش‌فرض | شرح |
|--------|---------|------|
| `HERMES_BALE_TEXT_BATCH_DELAY_SECONDS` | مقدار هرمس | تأخیر بین دسته‌های متن (برای جریان روان پاسخ‌های بلند) |
| `HERMES_BALE_TEXT_BATCH_SPLIT_DELAY_SECONDS` | مقدار هرمس | تأخیر بین پیام‌های جداگانه در یک پاسخ |
| `HERMES_BALE_MEDIA_BATCH_DELAY_SECONDS` | `0.8` | تأخیر بین ارسال‌های رسانه |

مثال: برای پاسخ سریع‌تر، تأخیر متن را کم کنید:

```bash
HERMES_BALE_TEXT_BATCH_DELAY_SECONDS=0.2
```

---

## تأیید تغییرات

بعد از هر تغییر، گیت‌وی را ری‌استارت کنید:

```bash
hermes gateway restart
```

و سپس با پیام دادن به ربات، رفتار جدید را بررسی کنید. برای تست سریع دسترسی،
با یک حساب دوم (که در allowlist نیست) پیام بفرستید — باید رد شود.
