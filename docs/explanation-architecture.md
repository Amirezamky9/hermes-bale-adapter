# معماری: چرا این پلاگین «یک کپی از پلاگین تلگرام» است؟

این صفحه توضیح می‌دهد که **چرا** پلاگین بله این‌گونه ساخته شده: کپی از تلگرام،
با تغییرات هدفمند. اگر فقط می‌خواهید نصب کنید، این صفحه لازم نیست؛ اگر می‌خواهید
بفهمید چه خبر است و چرا کار می‌کند، این صفحه برای شماست.

---

## مشکل

هرمز یک آداپتور کامل و بالغ برای تلگرام دارد: استریمینگ، دکمه‌ها، رسانه،
نشانگر تایپ، ری‌کانکت، مدیریت موضوعات (topics)، و ده‌ها قابلیت دیگر که طی سال‌ها
توسعه یافته‌اند.

پیام‌رسان بله (Bale) یک پلتفرم ایرانی است که **Bot API اش تقریباً ۹۰٪ با
تلگرام سازگار است** — حتی کتابخانهٔ `python-telegram-bot` هم (با یک `base_url`
متفاوت) با آن کار می‌کند.

اگر بخواهیم یک آداپتور بله را از صفر بنویسیم، باید همهٔ آن قابلیت‌های بالغ را
دوباره پیاده کنیم — ماه‌ها کار و هزاران خط کد برای چیزی که قبلاً وجود دارد.

---

## رویکرد: کپی، سپس تغییر هدفمند

به‌جای بازنویسی، تصمیم گرفته شد:

1. **کپی کامل** از پلاگین تلگرام (پوشه `telegram/` → `bale/`)
2. **تغییر فقط چیزهایی که واقعاً در بله متفاوت است**
3. **تست end-to-end** روی بله واقعی

این یعنی همهٔ قابلیت‌های پیشرفتهٔ تلگرام (استریمینگ، دکمه‌ها، رسانه، ری‌کانکت)
**رایگان** به بله منتقل شدند — چون همان کد، همان رفتار.

```
┌─────────────────────────────────────────────┐
│           پلاگین تلگرام (telegram/)          │
│  adapter.py · ids.py · network.py · ...     │
└──────────────────────┬──────────────────────┘
                       │ cp -r (کپی کامل)
┌──────────────────────▼──────────────────────┐
│           پلاگین بله (bale/)                 │
│  adapter.py → BaleAdapter                   │
│  ids.py     → bale_ids.py                   │
│  network.py → bale_network.py               │
└──────────────────────┬──────────────────────┘
                       │ تغییرات هدفمند
                       ▼
        ┌───────────────────────────────────┐
        │  ۱. base_url → tapi.bale.ai/bot   │
        │  ۲. ParseMode: MARKDOWN (نه V2)   │
        │  ۳. پیکر مدل: فارسی + RTL         │
        │  ۴. fallback transport بله        │
        │  ۵. env: BALE_* به‌جای TELEGRAM_* │
        └───────────────────────────────────┘
```

## دقیقاً چه چیزی تغییر کرد؟

### ۱. نقطه اتصال (base_url)

| | تلگرام | بله |
|---|---------|------|
| URL | `https://api.telegram.org/bot<TOKEN>/...` | `https://tapi.bale.ai/bot<TOKEN>/...` |
| فایل | `https://api.telegram.org/file/bot<TOKEN>/...` | `https://tapi.bale.ai/file/bot<TOKEN>/...` |

یک نکتهٔ ظریف: `python-telegram-bot` انتظار دارد `base_url` به `/bot` ختم شود
(چون token را مستقیم به انتها می‌چسباند). در غیر این صورت URL به‌صورت
`https://host<TOKEN>` ساخته می‌شود و خطای `Invalid port` می‌دهد. این دقیقاً
باگی بود که در توسعه کشف و رفع شد.

### ۲. حالت رندر (Parse Mode)

بله از **Markdown** و **HTML** پشتیبانی می‌کند، اما **MarkdownV2** (که تلگرام
دارد) را نه. بنابراین:

- `ParseMode.MARKDOWN_V2` → `ParseMode.MARKDOWN`
- تابع `format_message` بازنویسی شد: بدون escapeهای مخصوص V2
- جدول‌ها به بولت‌لیست تبدیل می‌شوند (بله جدول markdown را نمی‌فهمد)

### ۳. پیکر مدل — فارسی و راست‌به‌چپ

بله یک اپ فارسی است و دکمه‌های inline را **راست‌به‌چپ** رندر می‌کند. برای اینکه
انتخاب مدل (`/model`) طبیعی دیده شود:

- دکمه‌های «بعدی» / «قبلی» / «بازگشت» / «انصراف» — فارسی
- ترتیب آرایهٔ دکمه‌ها برعکس شد تا «بعدی» سمت راست و «قبلی» سمت چپ بماند
  (زیرا بله آرایه را RTL نمایش می‌دهد)
- نام مدل‌های بلند کوتاه می‌شوند و پسوند `:free` حذف می‌شود تا در دکمه جا شوند

### ۴. ترابرد شبکهٔ جایگزین

بله یک سرویس ایرانی است و گاهی شبکه یا DNS دچار مشکل می‌شود. فایل
`bale_network.py` یک ترابرد جایگزین (`BaleFallbackTransport`) ارائه می‌دهد که
وقتی `tapi.bale.ai` قابل دسترس نیست، از IP مستقیم استفاده می‌کند تا ربات قطع نشود.

### ۵. متغیرهای محیطی و شناسایی

- `TELEGRAM_*` → `BALE_*` (مثلاً `BALE_BOT_TOKEN`)
- `TelegramAdapter` → `BaleAdapter`
- `Platform.TELEGRAM` → `Platform("bale")`
- نام قفل (lock) → `'bale-bot-token'`

### ۶. چیزهایی که **عمداً** تغییر نکردند

- نام متدهای دیتابیس (مثل `delete_telegram_topic_binding`) — چون این‌ها نام
  ستون‌های دیتابیس هستند و ربطی به پلتفرم ندارند؛ تغییرشان باعث شکستن مهاجرت‌ها
  می‌شد.

## معاوضه‌ها (Trade-offs)

- **مثبت:** تمام قابلیت‌های تلگرام رایگان منتقل شدند؛ هیچ بازنویسی لازم نبود.
- **منفی:** کد شامل بخش‌هایی است که برای بله بی‌ربط‌اند (مثل مدیریت topic های
  تلگرام یا MarkdownV2). این «وزن اضافه» قابل قبول است چون هزینهٔ نگهداری یک
  نسخهٔ جداگانه را حذف می‌کند.
- **منفی:** وابسته به رفتار `python-telegram-bot` هستیم؛ اگر کتابخانه URL یا
  رفتارش را تغییر دهد، باید دوباره تطبیق دهیم.

## جایگزین‌های بررسی‌شده

- **نوشتن از صفر:** رد شد — ماه‌ها کار برای چیزی که با ۵ تغییر کوچک حل می‌شد.
- **استفاده از SDK رسمی بله:** بله SDK رسمی کامل و بالغی برای Python ندارد؛
  کتابخانهٔ telegram-bot با تغییر base_url، انتخاب عملی‌تر بود.

---

## خلاصه

پلاگین بله = **کدِ تلگرام + ۵ تغییر هدفمند**. این یک تصمیم معماری عمدی است، نه
تنبلی: وقتی دو پلتفرم ۹۰٪ سازگارند، نگهداری دو پیاده‌سازی جداگانه یک
بدهیِ بی‌معنی است. نسخهٔ بله هم‌زمان با تلگرام، تمام قابلیت‌ها را حفظ می‌کند و
هر بهبود آیندهٔ تلگرام را به‌صورت خودکار می‌گیرد.
