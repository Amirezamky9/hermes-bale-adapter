# راهنمای کامل پلاگین بله (Bale) برای Hermes Agent

> این سند، مستندات کامل فارسی پلاگین **بله** است — یک آداپتور پیام‌رسان برای
> [Hermes Agent](https://github.com/NousResearch/hermes-agent) که ارتباط شما را با
> ربات بله برقرار می‌کند.

---

## این مستند برای چه کسی است؟

- **تازه‌کارها**: از بخش «آموزش راه‌اندازی» شروع کنید تا در چند دقیقه ربات بله خود را بالا بیاورید.
- **کاربران عادی**: بخش «راهنمای نصب» و «راهنمای شخصی‌سازی» را دنبال کنید.
- **توسعه‌دهندگان**: بخش «مرجع فنی» و «معماری» را بخوانید تا بفهمید چرا و چگونه این پلاگین کار می‌کند.

## خلاصهٔ یک‌جمله‌ای

این پلاگین یک **کپی فنی از پلاگین تلگرام** است که فقط تغییرات لازم برای کار با
**پیام‌رسان ایرانی بله** را دریافت کرده است — چون API بله تقریباً ۹۰٪ با
Bot API تلگرام سازگار است. نتیجه: تمام قابلیت‌های پیشرفته (استریمینگ، دکمه‌ها،
فایل، تایپ‌ایندیکیتور و...) بدون بازنویسی، در بله هم کار می‌کنند.
