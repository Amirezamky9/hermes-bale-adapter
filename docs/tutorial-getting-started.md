# آموزش راه‌اندازی سریع: از صفر تا اولین پیام در بله

در این آموزش، یک ربات بله می‌سازید و آن را به Hermes Agent وصل می‌کنید، به صورتی
که بتوانید از داخل بله با هوش مصنوعی خودتان چت کنید. **تا پایان گام ۳، اولین
پاسخ را می‌بینید** — پس سریع پیش می‌رویم.

---

## چه چیزهایی نیاز دارید

- یک Hermes Agent نصب‌شده (روی هر سیستم‌عامل: لینوکس، macOS، ویندوز، یا داکر)
- دسترسی به `python3` و `pip`
- یک حساب بله (برای ساخت ربات)

اگر هنوز Hermes نصب نکرده‌اید، ابتدا [مستندات نصب Hermes](https://hermes-agent.nousresearch.com/docs) را دنبال کنید، سپس برگردید.

---

## گام ۱: یک ربات در بله بسازید

1. در اپلیکیشن بله، به [@botfather](https://ble.ir/botfather) پیام دهید.
2. دستور `/newbot` را بفرستید.
3. یک نام برای ربات انتخاب کنید (مثلاً «دستیار من»).
4. یک نام کاربری (یوزرنیم) که به `bot` ختم شود وارد کنید (مثلاً `my_assistant_bot`).
5. بله یک **توکن** به شما می‌دهد — آن را کپی کنید.

    توکن به این شکل است:
    ```
    123456789:ABCdef123GHIklm456NOPqrs789TUVwxyz01
    ```
    این توکن مثل رمز عبور است. آن را به کسی ندهید و در جایی امن نگه دارید.

> ✅ چی دیدید؟ در این گام، یک ربات با توکن مخصوص خودش ساختید.

---

## گام ۲: پلاگین را بسازید و فایل‌های محیطی را تنظیم کنید

### ۲-۱: پلاگین را در Hermes فعال کنید

فایل `~/.hermes/config.yaml` را باز کنید و این بخش را اضافه یا ویرایش کنید:

```yaml
gateway:
  platforms:
    bale:
      enabled: true
      token: 123456789:ABCdef123GHIklm456NOPqrs789TUVwxyz01   # توکن ربات خودتان
      extra:
        allow_from:
          - '66881162'        # شناسه عددی حساب بله خودتان (فقط خودتان بتوانید چت کنید)
      home_channel:
        chat_id: '66881162'   # برای ارسال اعلان‌ها و گزارش‌ها به همین چت
        name: پیام شخصی
```

> شناسه عددی حساب خودتان را چگونه پیدا می‌کنید؟ ساده‌ترین راه: یک پیام به
> ربات بزنید و در بخش «مرجع فنی» نحوهٔ دیدن شناسه خود را بخوانید.

### ۲-۲: متغیر محیطی توکن را تنظیم کنید

فایل `.env` را از نمونه بسازید و توکن را پر کنید:

```bash
cd ~/.hermes/plugins/platforms/bale
cp .env.example .env
```

سپس `.env` را ویرایش و توکن را وارد کنید:

```bash
BALE_BOT_TOKEN=123456789:ABCdef123GHIklm456NOPqrs789TUVwxyz01
BALE_ALLOWED_USERS=66881162
```

> ✅ در این گام، پلاگین را فعال و توکن را تنظیم کردید — پیکربندی اولیه آماده است.

---

## گام ۳: گیت‌وی را ری‌استارت کنید و اولین پیام را ببینید

گیت‌وی هرمس را ری‌استارت کنید تا پلاگین بارگذاری شود:

```bash
hermes gateway restart
```

اگر گیت‌وی در daemon/داکر اجرا می‌شود، طبق مستندات همان محیط ری‌استارت کنید.

سپس در بله، به ربات خودتان پیام بدهید:

```
سلام! چه خبر؟
```

عدد `1/8`... اگر همه‌چیز درست باشد، ربات ظرف چند ثانیه پاسخ می‌دهد.

> ✅ **به اولین نتیجهٔ واقعی رسیدید:** ربات بله شما زنده است و با هوش مصنوعی
> Hermes صحبت می‌کند.

---

## گام ۴: دستورهای مفید را امتحان کنید

ربات شما از دستورهای اسلش پشتیبانی می‌کند:

| دستور | کاربرد |
|--------|--------|
| `/model` | تغییر مدل هوش مصنوعی (با دکمه‌های فارسی) |
| `/new` | شروع یک گفتگوی تازه |
| `/stop` | توقف پردازش فعلی |
| `/sethome` | تنظیم این چت به‌عنوان مقصد پیش‌فرض اعلان‌ها |
| `/help` | فهرست کامل دستورها |

برای دیدن همهٔ دستورها، `/commands` را بفرستید.

---

## گام ۵: ارسال فایل، عکس و صدا

ربات بله از رسانه پشتیبانی می‌کند:

- 📷 یک عکس بفرستید — ربات محتوای آن را تحلیل می‌کند.
- 📄 یک فایل (مثل PDF یا سند) بفرستید — ربات آن را می‌خواند.
- 🎤 یک پیام صوتی بفرستید — ربات آن را گوش می‌دهد.

برای ارسال یک فایل به ربات، کافیست آن را در چت بفرستید و بپرسید: «اینو بخون و خلاصه کن».

---

## چه ساختید؟

شما یک ربات **بله** ساختید که به Hermes Agent وصل است و می‌تواند:

- متن، عکس، فایل و صدا را بفهمد و پاسخ دهد
- مدل هوش مصنوعی را از داخل بله عوض کنید
- دستورهای اسلش را اجرا کند
- از طریق `/sethome` مقصد اعلان‌های cron را تعیین کنید

## عیب‌یابی سریع

**ربات پاسخ نمی‌دهد؟**
1. مطمئن شوید توکن در `config.yaml` و `.env` یکسان است.
2. چک کنید گیت‌وی بالا آمده: `hermes gateway status`
3. در لاگ گیت‌وی دنبال خطای `[Bale]` بگردید: `tail -f ~/.hermes/logs/gateway.log`

**پیام «شما مجاز نیستید» می‌بینید؟**
- شناسه شما در `allow_from` / `BALE_ALLOWED_USERS` نیست. آن را اضافه کنید.

**تایپ می‌کنید ولی ربات «در حال فکر کردن» می‌ماند؟**
- به ربات بیشتر زمان بدهید، یا `/stop` بزنید و دوباره تلاش کنید.
